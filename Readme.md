# Seemal Shahid — Personal Profile Website

A responsive personal profile website for Seemal Shahid, a Pharmacy Student at the University of Central Lancashire (UCLan), Preston, UK.

## Features

- Responsive mobile-first layout
- Light and dark mode, with saved preference
- Accessible navigation and keyboard support
- Reduced-motion support
- Smooth scrolling and subtle entrance animations
- Search-engine and social-sharing metadata
- No frameworks or paid dependencies
